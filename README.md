# 📱 ChatConnect - Real-Time Android Messaging App

A modern, real-time Android chat application built with **Kotlin**, **Jetpack Compose**, and **Firebase**. This app allows users to create accounts, find friends, and send messages instantly in a clean, responsive UI.

## ✨ Features

* **User Authentication:** Secure Sign Up and Log In using Firebase Authentication (Email & Password).
* **Real-Time Messaging:** Instant message delivery and UI updates using Firebase Firestore `SnapshotListeners`.
* **User Directory:** View a list of all registered users and tap to start a conversation.
* **Modern UI:** Fully declarative and responsive user interface built entirely with Jetpack Compose.
* **Chat Bubbles:** Distinct styling for sent and received messages (WhatsApp-style layout).

## 🛠️ Tech Stack

* **Language:** [Kotlin](https://kotlinlang.org/)
* **UI Toolkit:** [Jetpack Compose](https://developer.android.com/jetpack/compose)
* **Backend/Database:** [Firebase Cloud Firestore](https://firebase.google.com/docs/firestore)
* **Authentication:** [Firebase Authentication](https://firebase.google.com/docs/auth)
* **Asynchronous Programming:** Kotlin Coroutines & Flows
* **Architecture:** MVVM (Model-View-ViewModel)
